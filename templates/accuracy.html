How accurate is this, really?

Most forecasting tools show you a confident number and stop there. We think you deserve to see the actual error rate — per climate zone, measured against real held-out data, compared to the simplest possible baseline. No cherry-picked demo numbers.

How to read this

Model MAE is the average size of the model's mistake, in kW — lower is better. Persistence baseline is the simplest forecast possible: "assume this hour looks like the same hour yesterday." Any real model has to beat that to prove it's doing something useful, not just producing plausible-looking numbers. Skill score is how much better than that baseline the model actually is. We report both numbers, not just the second one, because a skill score with nothing to check it against is just a claim.

What this page does not claim: validation against real metered household output in Nigeria — that dataset doesn't exist yet publicly, so these numbers are measured against real historical weather data, with power output derived from a documented physical model rather than a meter. That distinction is explained in full on the About page.

Built with real weather data (Open-Meteo) and real historical solar data (NASA POWER) for Nigeria.
